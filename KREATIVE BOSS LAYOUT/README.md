# KREATIVE BOSS

An independent creative web studio portfolio built as a lightweight static site.

## Run it

Open `index.html` in a current browser. There is no build step or dependency installation. Google Fonts are optional; system fonts are used as a fallback. The supplied logo is stored unchanged at `assets/kreative-boss-logo.png`.

## Experience

- A WebGL ray-marched sculpture reacts to pointer, drag, keyboard and page progress, with a CSS fallback when WebGL is unavailable.
- Four clearly identified concept projects open full-screen case studies and interactive previews.
- The capabilities lab demonstrates six disciplines; the process illustration changes with scroll; the manifesto typography follows the scroll position.
- The project inquiry collects name, company, project type, needs, budget, timeline, email and description, then opens the visitor's email app addressed to the studio.
- Touch and reduced-motion modes simplify pointer and animation behavior.
